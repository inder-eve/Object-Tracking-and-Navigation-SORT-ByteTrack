# Tank Object Tracking using YOLO

This project demonstrates a prototype computer vision pipeline for detecting and tracking tanks in video streams.

## Features
- YOLO-based object detection
- Multi-object tracking using SORT / ByteTrack
- Unique ID assignment per tracked object
- Video input and output support

## Tech Stack
- Python
- OpenCV
- YOLOv8
- SORT / ByteTrack

## Use Case
Prototype for UAV-based visual target tracking and vision-based navigation systems.

## Note
Trained weights and datasets are not included due to size constraints.
